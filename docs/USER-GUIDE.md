# 市集銷售記錄 — 使用說明

> 這份說明是給創作者看的，用平常說話的方式寫。如果看完還有問題，直接傳給工程師。

---

## 第一次使用：開網址、登入、加到主畫面

工程師會給你一個網址（格式像 `https://你的應用.web.app`）。

1. 用手機瀏覽器開啟那個網址。
2. 點「**使用 Google 登入**」，用你自己的 Google 帳號登入。登入只需要做一次，之後開 App 就自動保持登入狀態。你和夥伴各自用自己的 Google 帳號登入即可，兩人看到、編輯的是同一本帳，不需要共用同一個帳號密碼。
3. 登入後，**把 App 加到主畫面**，以後直接從桌面開，比較方便，也比較不容易因為瀏覽器清快取而出問題。

**iPhone（Safari）加到主畫面的方法：**

1. 確認用 Safari 開啟（不是 Chrome 或其他瀏覽器）。
2. 點畫面下方中間的「分享」按鈕（方框加箭頭的圖示）。
3. 滑到下面，選「**加入主畫面**」，再點右上角「新增」。

**Android（Chrome）加到主畫面的方法：**

1. 用 Chrome 開啟網址。
2. 點右上角三個點的選單。
3. 選「**新增到主畫面**」或「**安裝應用程式**」（不同版本文字略有不同）。

## 日常記帳：照舊用就好

登入後，畫面下方有五個分頁：**記銷售、商品、場次、線上、匯出**。

**記一筆銷售（擺攤現場）：**

1. 切到「**記銷售**」分頁（預設就在這裡）。
2. 有進行中場次時，「記帳目標」預設是「**本場次**」。
3. 點你要賣的商品按鈕，可以多選。每個商品旁邊會出現數量，點 `+` / `-` 調整。
4. 選**付款方式**（現金 / 轉帳）。
5. 點「**結帳**」，這筆銷售就記好了。

**現場臨時新增商品：**

切到「**商品**」分頁，填品名和單價，按「新增商品」，馬上就可以在記銷售畫面看到、點選。

**贈送 / 補送：**

選商品後，在類型那裡選「**贈送**」或「**補送（補寄）**」。這兩種類型會扣掉帶貨數量，但**不計入收入**，讓你的帳不會被送出去的東西汙染。

## 線上銷售：沒擺攤、或這個月沒出攤也能記帳

有時候買家是直接匯款、私訊下單，不是在攤位上成交的。這種情況不需要開場次，直接記「線上」就好：

1. 切到「**記銷售**」分頁。如果目前沒有進行中的場次，「記帳目標」會自動是「**線上**」；如果剛好有進行中場次，把「記帳目標」切成「**線上**」即可。
2. 選商品、調數量，跟平常記帳一樣。
3. 填「**日期**」：預設是今天，如果是補記幾天前的匯款，改成實際收到錢的那天。
4. 填「**備註**」（選填）：可以寫買家的 IG、信箱、姓名，方便之後對帳認人。
5. 點「**結帳**」完成。

**回頭看線上銷售、修改、刪除：**

切到「**線上**」分頁，會依月份分組列出所有線上銷售，每個月上面顯示那個月的營收小計。點任一筆可以「編輯」（改品項、日期、備註等）或「刪除」。

> 備註欄位不只線上銷售能用——擺攤現場記的銷售，事後在「場次」分頁編輯那一筆時，一樣可以補上備註。

## 沒網路也能記帳

**有沒有網路都可以記帳。** App 會先把紀錄存在你的手機上，等連上網路後，自動把這段期間的紀錄傳到雲端。整個過程你不需要做任何事。

**畫面上可能出現「有 N 筆尚未上雲」**，這是在告訴你，有幾筆紀錄還沒傳上去（通常是因為當下沒有網路）。這是正常的，不用緊張，也不用手動做什麼——連上網路後，App 會自己處理，提示就會消失。

消失後會顯示「所有紀錄已上雲」，代表一切正常。

---

## 換裝置、用電腦看報表

**任何裝置**（手機、平板、電腦）只要：

1. 開啟同一個網址
2. 用同一個 Google 帳號登入

就看得到完全一樣的資料。不需要轉檔、不需要傳給自己，直接打開就有。

---

## 場次報表怎麼看

切到「**場次**」分頁，就可以看目前進行中（或過往）場次的報表。

報表包含：

- **收入**：這場的銷售總金額（不含贈送/補送）
- **淨額**：收入扣掉商品成本和場次固定費用（攤租、交通等）後，實際落口袋的金額
- **每日分計**：每一天各賺了多少、賣了幾筆
- **帶/賣/剩**：每個商品這場帶了幾件、賣出幾件、還剩幾件
- **好賣排行**：按銷售量排名

---

## 改錯了怎麼辦

**在場次報表裡就可以直接改：**

1. 切到「**場次**」分頁，點開你要修改的場次。
2. 找到那筆銷售，點右邊的「**編輯**」或「**刪除**」。
3. 編輯後儲存，或確認刪除，報表會立刻更新。

**看修改歷史：**

切到「**匯出**」分頁，向下滑可以看到「**修改歷史**」。每次對銷售的新增、編輯、刪除都會留一條紀錄，顯示：

- 發生時間
- 動作（新增 / 編輯 / 刪除）
- 那筆銷售的摘要
- 改了什麼（如果是編輯，會標示前後差異）

修改歷史**只能看，不能在這裡修改**。

## Google 試算表的流水帳

如果工程師有幫你設好「試算表同步」，每一筆記帳都會自動出現在你的 Google 試算表裡。這張表就像流水帳，可以直接用來對帳或給別人看。

幾個重要規則：

- **你刪除一筆銷售**，試算表對應那列不會消失，但「狀態」欄會標上「已刪除」，保留記錄。
- **你編輯一筆銷售**，試算表對應那列的內容會自動更新。
- **試算表只是讓你看的**。請不要直接在試算表裡修改數字、刪除列，這樣不會影響 App 的資料，反而會讓兩邊不一致。**以 App 為主。**

## 備份與還原：雲端自動幫你存，JSON 是保險

### 平常不用手動備份

因為 App 已經把你的資料自動同步到雲端，你的資料同時存在你的手機和雲端，不需要每次收攤後特地備份。

### JSON 備份：搬家或保險用

如果你想把資料搬到另一支手機、或是想留一份在自己電腦當保險，可以匯出 JSON 備份：

1. 切到「**匯出**」分頁。
2. 點「**備份全部資料（JSON，可還原）**」，下載這個檔案存好。

### 從備份還原

如果需要從 JSON 備份把資料搬回來（例如換手機、或工程師交接）：

1. 切到「**匯出**」分頁。
2. 在「從備份還原」的地方，選擇你的 JSON 備份檔。
3. 確認後，備份裡的資料會**合併上傳到雲端**，不會刪除你已有的其他資料。

## 出問題前，先自己確認幾件事

在找工程師之前，先檢查以下幾點，可以省很多時間：

1. **有網路嗎？** 試試看用瀏覽器開一個其他網頁，確認手機有連上網。
2. **登入的是對的 Google 帳號嗎？** 點右上角帳號圖示或切到「匯出」分頁看登入狀態，確認是你的帳號。
3. **畫面上有沒有任何提示文字？** 拍照或截圖存下來，一起傳給工程師，讓他能更快找到問題。

如果以上都確認了還是有問題，把截圖和「發生了什麼」傳給工程師就好。
